# 🎵 Melodream

> **Music that feels like a dream.**

Melodream is a modern, responsive **Single Page Application (SPA)** music player built with **Vanilla JavaScript and Tailwind CSS**.

This project was created to practice building a dynamic and interactive web application without relying on JavaScript frameworks like React. It combines a clean music-focused interface with JavaScript-powered navigation, music controls, dynamic content, and responsive layouts.

🔗 **Live Demo:** [Melodream](https://behrokh-dev.github.io/Melodream/)

---

## ✨ Features

- 🎧 Modern and responsive music player interface
- 📱 Fully responsive design for desktop, tablet, and mobile
- ⚡ Single Page Application (SPA) experience
- 🧭 Dynamic navigation without page reloads
- 🎵 Music playback controls
- ⏯️ Play / Pause functionality
- ⏭️ Next and Previous track controls
- 🔊 Volume control
- 📊 Interactive progress bar
- ❤️ Liked Songs section
- 🎼 Music Categories
- 👨‍🎤 Popular Artists section
- 🇮🇷 Persian Artists collection
- 🌎 International Artists collection
- 💿 Albums and Playlists interface
- 🔎 Search functionality
- 🎨 Modern UI with Tailwind CSS
- ✨ Smooth interactions and hover effects
